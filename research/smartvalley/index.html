상담 진행 (8월 고벤처포럼 · 20분)

이 상담은 발견용 20분이다. 짧으니 처방을 늘어놓지 말고, 도메인·단계·매출·예산 네 가지만 정확히 확보한다. 상담은 항상 "대표님, 지금 사업 단계 알려 주세요 + 지금 파는 게 정해졌나요, 아니면 무엇을 팔지가 고민이세요?"로 연다. 톤: 초기 대표 = 응원하되 막연한 "브랜딩" 화법 금지, "무엇을 파는 회사인지"부터 함께 정리.

사업 단계 — 스마트벨리 = STAGE 0~1 (상담에서 확정)

STAGE 0 · 사업모델 미정 ★후보
매출 0 + "무엇을 팔지" 미정/여러 갈래. 아이템·타겟 탐색 중.
역할 → 포지셔닝·워크숍·정부지원 매칭(Land&Expand)
STAGE 1 · 런칭 전 ★후보
팔 게 정해졌고 전환 배관만 없음.
역할 → 첫 고객 전환 경로 + 포지셔닝
STAGE 2~3 · 런칭·매출
제품·채널·매출 있음.
역할 → 점검·개선 / 캠페인
단계 분기 질문 — 이걸로 STAGE를 못 박는다① 지금 파는 게 정해졌나요, 무엇을 팔지가 고민이세요? (미정·여러 갈래 → STAGE 0 / 확정 → STAGE 1) · ② 지금 매출이 나오나요? (0 → STAGE 0~1 확정). "런칭 전"이라고 STAGE 1로 반올림하지 말 것 — 두 단계는 역할·결제가 완전히 다르다.

상담 흐름 (20분 압축 4단계)

1 · 소개 청취 (5분)
"스마트벨리가 어떤 서비스예요?" — 무엇을 파는 회사인지부터. 앱/SaaS/플랫폼/스마트팜 중 무엇인지 특정하고 메모.
2 · 단계·매출 체크 (5분)
위 분기 질문으로 STAGE 확정. 매출·팀·법인 여부·(있다면) 앱/홈페이지 함께 열어봄.
3 · 급한 것 도출 (5분)
"지금 가장 급한 게 뭐예요?" — 아이템 정리 / 첫 고객 / 자금(정부지원) / 홍보 중 무엇인지 대표 입으로.
4 · 입구 제안 (5분)
STAGE 0 → 정부지원 매칭 + 소액 포지셔닝 워크숍. STAGE 1 → 첫 전환 배관 소형 패키지. 큰 견적 X — 관계 붙잡기.
아이스브레이킹"고벤처포럼까지 직접 오셔서 상담 신청하신 것 보면 지금 사업에 진심이신 게 느껴져요. 그런데 저희가 미리 찾아봤는데 '스마트벨리'가 워낙 이름이 겹치는 데가 많아서 — 정확히 어떤 서비스를 만드시는 건지부터 좀 여쭤봐도 될까요?" → 실체 확인을 자연스럽게 개시.

반드시 물어볼 질문 Top 3 (20분이라 3개로 압축)

Q1 · 예산 성격 / 단계 (1순위)
"지금 마케팅에 쓸 수 있는 예산이 있으세요, 아니면 정부지원부터 알아보는 단계세요? 그리고 지금 파는 게 정해졌나요, 무엇을 팔지가 고민이세요?"
예산 성격 + STAGE 0/1 분기 — 입구 설계의 뿌리
Q2 · 서비스 실체 + 네이밍
"스마트벨리가 정확히 어떤 서비스예요? (앱·B2B·플랫폼·스마트팜?) 그리고 '스마트벨리'라는 이름은 어떻게 지으셨어요?"
실체 특정(리서치로 못 잡음) + 어원에서 정체성·차별점 단서
Q3 · 지금 가장 급한 것
"지금 제일 급한 게 뭐예요 — 아이템 정리, 첫 고객, 자금, 홍보 중에? 6개월 뒤 어떤 모습이면 성공이세요?"
진짜 니즈 확인 + STAGE 0 Land&Expand 입구 매칭
예상 반론 대비"마케팅/브랜딩 해주세요" → "그 전에 무엇을·누구에게 팔지가 뾰족해야 마케팅비가 안 새요. 지금 단계엔 그걸 먼저 잡는 게 훨씬 남습니다." · "예산이 별로 없어요" → "그래서 정부지원부터 같이 봐드릴게요 — 예비/초기창업패키지가 정공법이에요(무료 안내)." · "이미 다 정해졌어요" → "그럼 첫 고객 전환 경로부터. 큰 계약 전에 작게 시작하시죠."
상담 후 액션당일~24h — 감사 + 확인된 사실 정리(서비스 실체·STAGE·매출·예산 성격) + 정부지원 1~2건 링크(예비/초기창업패키지·BOUNCE 오픈이노베이션). 실체가 잡히면 이 PREP을 v2로 재작성(도메인 기반 시장·경쟁·처방). 초기라 견적서보다 관계·정보 제공이 먼저.
확신도 · 재검증이 PREP의 확신도는 55% (낮음) — 실체 미확인이 원인이다. 상담 5분이면 대부분 해소된다. 억지 처방보다 정직한 발견이 이 건의 정답.

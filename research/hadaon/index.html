수주 한 장
먼저 확인할 것 & 진짜 니즈 (가설)
먼저 확인 = "지금 파는 게 정해졌나요, 아니면 무엇을 팔지가 고민인가요?" + "지금 나오는 매출이 있나요?" — 이 두 답으로 STAGE가 갈린다. 진짜 니즈(가설) = 제품·광고가 아니라 '무엇을·누구에게 팔지' 방향 결정과 첫 포지셔닝. 신청 이메일의 'mktg'(마케팅) 단서 = 셀러·마케팅 대행 관심 추정. 하지만 자사몰·스토어·SNS 흔적이 라이브로 잡히지 않음 → 실체는 상담에서만 확인 가능.
그래서 우리가 해주는 것 (STAGE 0 입구)
① 방향 정리 코칭 — "무엇을·누구에게·어떤 순서로" 여러 갈래를 우선순위로 좁히는 1:1 포지셔닝 워크숍
② 정부지원 매칭(선행 호의) — 예비창업 아이디어 단계에서 신청 가능한 창업 프로그램·(등록 후) 소상공인 온라인 판로 매칭. 비용 거의 0 = 관계·신뢰 구축
③ 소액 입구 → 졸업 트리거 — 사업 모델 확정 + 지원금 확보 시 본 견적(포지셔닝·IMC)으로 전환하는 Land & Expand
첫 제안 & 다음 액션
선불 진단·대형 패키지는 부적합(매출 0·방향 미정). 소액 워크숍 코칭 + 정부지원 매칭으로 관계를 열고, 모델이 잡히면 졸업시킨다. 15분 1순위 청취 = ①무엇을 팔지 정해졌나 ②매출 여부 ③예산 성격(월/단발/없음).

상담 진행 (고벤처포럼 · 15분)

공개 기록이 없으니 첫 3분을 분류 질문에 쓴다. 상담은 "지금 파는 게 정해졌나요, 아니면 무엇을 팔지가 고민인가요?" + "지금 나오는 매출이 있나요?"로 연다 — 이 두 답이 STAGE와 처방을 통째로 결정한다. 톤: 예비창업 = 막연한 응원 대신 방향을 좁혀 주는 실무 코칭.

사업 단계 — 하다온 = STAGE 0 (추정)

STAGE 0 · 사업 모델 미정 ★하다온
무엇을·누구에게 팔지 미정. 매출 0. 여러 방향 동시 개방.
역할 → 방향·포지셔닝 워크숍 + 정부지원 매칭
STAGE 1 · 런칭 전
팔 게 정해짐(제품·가격 확정), 전환 배관만 없음.
역할 → 입구형 소형 세팅 패키지
STAGE 2~3 · 런칭·매출
채널·매출 있음. (하다온엔 아직 해당 없음 추정)
역할 → 점검·개선 / 리테이너
단계별 질문 — 먼저 STAGE를 확정한다답에 따라 분기: 매출 0 + 무엇 팔지 미정 → STAGE 0(워크숍·정부지원). 팔 게 정해짐 + 전환 동선만 없음 → STAGE 1(소형 세팅). 주의 "예비창업"이라고 STAGE 1로 반올림 금지 — 신호(매출·방향)로만 판정.

상담 흐름 (15분 · 4단계)

1 · 분류 (0~3분)
"파는 게 정해졌나 / 무엇을 팔지 고민인가" + "매출 나오나" + "예산이 월/단발/없음 중 뭔가" → STAGE·규모 확정.
2 · 실체 청취 (3~8분)
셀러/대행/자체상품 중 어느 방향인지, 지금까지 해본 것, 사업자 등록 여부, 소재지. 공개 기록이 없으니 여기서 그림이 처음 생긴다.
3 · 방향 좁히기 (8~13분)
여러 갈래면 우선순위 1~2개로 좁히는 질문. "누구에게 / 왜 그걸 사야 하나"를 즉석에서 함께 세워 본다.
4 · 입구 제안 (13~15분)
소액 워크숍 코칭 + 정부지원 매칭(창업 계열 2건)으로 다음 스텝 합의. 큰 견적 금지.
아이스브레이킹 + 이름 어원"하다온 — 이름 참 좋은데, 어떻게 지으셨어요?"(웹에 없는 최대 무기가 여기서 나온다, 상시 질문). 이어 "유통·커머스로 시작하신다고 봤어요. 지금은 파실 게 정해진 단계인가요, 아니면 무엇을 팔지부터 같이 볼 단계인가요?" → 방어감 없이 STAGE 확정.

반드시 물어볼 질문 Top 3

Q1 · 예산 성격 (1순위)
"이번 창업에 지금 쓸 수 있는 예산이 월 단위인지, 단발 프로젝트인지, 아직 없는지? 대략 규모는요?"
매출 0이라 envelope 산식이 안 선다 → 예산 성격이 규모·처방을 가른다(반복 누락 방지, 1번 고정)
Q2 · 파는 것 & 매출 (STAGE 판정)
"지금 파는 게 정해졌나요, 아니면 무엇을 팔지가 고민인가요? 셀러·대행·자체상품 중 어느 쪽에 가깝고, 지금 나오는 매출이 있나요?"
STAGE 0 vs 1 확정 — 페이지 전체 가설의 검증점
Q3 · 이름 어원 & 기대
"'하다온' 이름은 어떻게 지으셨어요? 그리고 오늘 상담에서 딱 하나 얻어 가고 싶은 게 있다면?"
웹에 없는 브랜드 스토리·진짜 기대 확보 (최대 무기 발굴)
예상 반론 대비"뭘 팔지는 아직 고민 중" → "그게 정상이고, 그걸 좁히는 게 오늘 목표예요. 채널·광고는 그다음입니다." · "돈 들이긴 부담" → "그래서 먼저 정부지원(창업 계열)부터 연결해 드리고, 유료는 방향 잡힌 뒤 소액 워크숍으로." · "마케팅부터 배우고 싶다" → "무엇을 파는지가 정해져야 마케팅이 먹혀요 — 순서를 같이 잡죠."
상담 후 액션당일 24h — 감사 + 핵심 3줄(STAGE 판정·방향 좁힌 결과·정부지원 2건 링크) + 미확인 변수(품목·매출·사업자·예산·소재지) 기록. 이 케이스는 진단서·견적서보다 관계 유지가 우선 — 소액 워크숍 안내 + 정부지원 알림으로 가볍게 연결.

수주 한 장 · STAGE 0
USP & 진짜 니즈 (가설)
USP = 아직 미확정. '고순'이라는 이름과 전통 발효 뉘앙스만 있고, 무엇을 파는 브랜드인지가 정의 전. 진짜 니즈(추정) = 마케팅 대행이 아니라 "무엇을·누구에게·어떤 순서로 팔지"를 함께 정하는 사업모델·포지셔닝 설계. 예비창업 = 전환 배관을 깔 대상(제품·가격·채널)이 아직 없다. 지금 광고·자사몰 견적을 내밀면 헛발질 — discovery가 먼저다.
그래서 우리가 해주는 것 (STAGE 0 플레이북)
① 사업모델·포지셔닝 워크숍 — 아이템 후보를 좁히고 "고순 = 무엇" 한 줄과 타겟·가격 가설을 함께 설계
② 정부지원사업 매칭(선행 호의) — 예비창업패키지·농식품 벤처창업 등 사업화 자금 트랙을 짚어 관계·신뢰 구축 (비용 거의 0)
③ 소액 코칭 + 분기 1:1 체크포인트 — 모델이 잡히고 지원금이 들어오면 본 견적(브랜딩·채널 세팅)으로 졸업
첫 제안 & 다음 액션
큰 패키지 금지. 소액 워크숍/1:1 코칭으로 입구를 열고, 지원사업 매칭으로 호의를 선행. 졸업 트리거 = "사업모델 확정 + 지원금 확보" 시 자동 본 견적 전환. 15분 1순위 청취 = ①무엇을·누구에게 팔지 정해졌나 ②지금 매출이 있나 ③'고순' 이름은 어떻게 지었나.

상담 진행 (예비창업 15분)

15분은 짧다. 진단이 아니라 분류가 목적 — "무엇을·누구에게 팔지 정해졌나 / 매출 있나"로 STAGE를 못 박고, '고순' 어원을 캐 무기를 확보한다. 톤: 예비창업 대표에게 대형 견적·전문용어 금지, 함께 정하자는 코치 자세.

사업 단계 — 고순 = STAGE 0 (가설)

STAGE 0 · 사업모델 미정 ★고순
무엇을·누구에게 팔지 미정, 매출 0. 퍼널 X — 워크숍·코칭으로 모델 설계.
역할 → discovery·사업모델·포지셔닝 워크숍
STAGE 1 · 런칭 전
팔 게 정해졌고 전환 배관만 없음.
역할 → 첫 매출 경로 세팅
STAGE 2~3 · 런칭·매출
운영 중 — 점검·개선·드라이브.
역할 → 진단·리테이너
분류 질문 — 이걸로 STAGE 판정① "지금 파는 게 정해졌나요, 무엇을 팔지가 고민인가요?" · ② "지금 나오는 매출이 있나요?" — 매출 0 + 아이템 미정이면 STAGE 0 확정. "예비창업 = STAGE 1"로 반올림 금지.

상담 흐름 (15분 압축)

1 · 분류 (0~4분)
위 2개 질문으로 STAGE 판정. "무엇을·누구에게 팔지 정해졌나 / 매출 있나"가 첫 질문.
2 · 어원·아이템 (4~9분)
"'고순' 이름은 어떻게 지으셨어요?" — 발효/전통 스토리·의도 청취. 카테고리(전통주/발효/농식품/기타) 확정.
3 · 제약 확인 (9~12분)
전통주면 면허·통신판매 규제 / 자본·시간·팀. 대표가 손댈 수 있는 레버가 뭔지.
4 · 다음 액션 (12~15분)
소액 워크숍/코칭 + 정부지원 매칭 제안. 졸업 트리거 합의. 대형 견적 X.
아이스브레이킹"창업 준비하신다고 들었어요 — '고순'이라는 이름이 벌써 좋네요, 잘 익은 발효 향 같은. 오늘은 뭘 팔지 정하는 것부터 같이 잡아보면 좋겠어요." → 이름 칭찬으로 어원 질문 자연 유도 + 함께-설계 프레임.

반드시 물어볼 질문

Q1 · 무엇을·누구에게 (1순위)
"지금 무엇을, 누구에게 파실지가 정해졌나요? 아니면 그걸 정하는 게 고민이세요? 지금 나오는 매출이 있나요?"
STAGE 0/1 분류 — 이 답이 상담 전체를 가른다
Q2 · 브랜드명 어원 (무기·필수)
"'고순'이라는 이름은 어떻게 지으셨어요? 발효·전통주 쪽 의도가 있으신가요?"
웹·자료에 없는 최대 무기 — 스토리·카테고리 확정
Q3 · 아이템·카테고리
"떠올리시는 아이템이 전통주·발효식품·농식품 중 어디에 가깝나요? 후보가 여럿이면 뭐가 있나요?"
방향 가설 검증 / 여러 갈래면 STAGE 0 확정
Q4 · 자원·제약 (예산 성격)
"자본·시간·팀은 어느 정도 준비되셨어요? 정부지원사업은 알아보고 계신가요?"
예산 성격(매체비/운영비/단발) + 지원금 레버 진입
Q5 · 기대
"오늘 상담에서 가장 얻고 싶은 한 가지는 뭐예요?"
표면 vs 진짜 니즈 확인 · 다음 액션 설계
예상 반론 대비"마케팅부터 해주세요" → "팔 게 정해지기 전 광고는 돈만 태웁니다 — 먼저 뭘·누구에게 팔지부터 같이 잡죠." · "돈이 별로 없어요" → "그래서 예비창업패키지 같은 지원금부터 매칭해 드릴게요. 큰 비용 없이 시작합니다." · "빨리 팔고 싶어요" → "가장 빠른 길이 아이템·타겟을 먼저 못 박는 겁니다."
상담 후 액션당일 — 감사 + STAGE 판정 3줄(무엇을·누구에게·매출) + 어원·카테고리 메모 + 정부지원 매칭 1~2건(예비창업패키지·농식품 벤처창업) 링크. STAGE 0이면 소액 워크숍/코칭 제안 + 졸업 트리거 명시. 대형 견적·진단서는 아이템 확정 후.
STAGE 0 좀비 방지소액 코칭이 시간만 빨리지 않도록 "사업모델 확정 + 지원금 확보 → 자동 본 견적 전환" 졸업 트리거를 첫 제안에 박는다.

비즈테이블랩 (BizTableLab)

예비창업 단계 · 업종 신고는 콘텐츠·미디어. 공개 실체는 라이브 리서치로 확인되지 않음(확신 ~55%). 이름(Biz+Table)으로 보아 창업·비즈니스 교육/콘텐츠·커뮤니티·매칭을 준비 중인 것으로 추정 — 무엇을 팔지부터 상담장에서 확정해야 하는 STAGE 0.

수주 한 장

15분 현장 상담 직전 이 카드 하나면 된다. 예비창업·공개 실체 미확인이라 아래는 전부 상담 전 가설 — 확정이 아니라 "무엇을 확인할지"의 지도다.

수주 한 장
USP & 진짜 니즈 (가설 · 확신 ~55%)
USP = 아직 정의되지 않음. 예비창업이라 팔 것·타겟·수익모델이 미정일 개연성이 높다. 추정 진짜 니즈 = "콘텐츠·미디어를 무기로 무엇을(교육/커뮤니티/매칭 중) 누구에게 어떤 순서로 팔지"를 함께 정리·검증하는 것. 표면 고민은 "홍보·마케팅을 어떻게 하나"로 오지만, STAGE 0의 진짜 병목은 사업 모델·포지셔닝 미확정이다. 퍼널·광고를 먼저 깔면 방향 없이 예산만 샌다.
그래서 우리가 해주는 것 (STAGE 0 입구)
① 방향 확정 워크숍 — "Biz+Table"이 실제로 무엇을 파는 사업인지 아이템·타겟·수익모델을 한 장으로 좁힌다 (discovery-first)
② 정부지원 매칭 — 예비창업 자금 트랙(더하기 창업·여성기업·예비창업패키지)을 붙여 비용 부담 없이 관계를 연다 (선행 호의)
③ 소액 포지셔닝·1:1 코칭 — 방향이 잡히면 콘텐츠 축·브랜드 언어를 세팅, 지원금 확보 후 본 견적으로 졸업(Land & Expand)
첫 제안 & 다음 액션
선불 대형 견적은 금물. 예비창업엔 소액 워크숍/코칭 + 정부지원 매칭을 입구로 관계를 붙잡고, 사업 모델 확정 + 지원금 확보를 졸업 트리거로 본 견적 전환. 15분 1순위 청취 = ①무엇을 팔지 정해졌나 ②지금 매출 나오나 ③예산 성격(자비/지원금/월운영).
DIAGNOSIS (가설)

핵심 진단

사업 모델 미확정 (STAGE 0)

"콘텐츠·미디어"라는 넓은 신고 외에 팔 것·타겟·수익모델이 공개적으로 드러나지 않음. 여러 갈래가 열려 있을 개연성 → 퍼널이 아니라 방향 설계가 먼저.

High

브랜드명 해석 = 유일 단서

Biz(비즈니스)+Table(테이블·라운드테이블)+Lab(실험실). 창업자들이 둘러앉는 "비즈니스 테이블" — 교육·커뮤니티·매칭 중 무엇인지가 상담 첫 확인 대상.

High

개인 프리메일 = 초기 신호

신청 이메일이 회사 도메인이 아닌 개인 프리메일(네이버) → 법인·자사 도메인 이전 이 아직 없는 극초기. 사업자등록 여부부터 확인.

진단 결론 (가설)"실체 미확인 = 나쁜 신호"가 아니라 "아직 만들어지는 중"이라는 신호. 이 상담에서 우리가 파는 건 광고·퍼널이 아니라 방향이다. 무엇을 팔지 한 장으로 좁히고(워크숍), 예비창업 자금을 붙여(정부지원 매칭) 관계를 여는 게 정석. 억지로 실체를 지어 처방하지 말 것.
확신 수준 — 정직 고지이 페이지의 사업 방향 추정(교육/커뮤니티/매칭) 확신은 50~55%에 불과하다. "Biz+Table+Lab"과 "콘텐츠·미디어" 업종에서 역산한 가설이며, 공개 근거가 없다. 상담 첫 3분은 사실 수집(뭘 팔지·매출·이름 어원)에 쓰고, 그 답이 나온 뒤에야 처방을 얹는다.

SWOT (가설 · 극초기)

Strengths

  • 대표 본인이 직접 신청·상담 참여 = 의사결정 즉시
  • 백지 상태 = 포지셔닝·브랜드를 처음부터 바르게 설계 가능
  • 예비창업 = 정부지원 자금 트랙 다수 자격

Weaknesses

  • 팔 것·타겟·수익모델 미확정 (STAGE 0)
  • 공개 실체·채널·트랙레코드 전무
  • 예산 규모 미확인 — 자비 부담 여력 불투명

Opportunities

  • 정부 예비창업 지원(자금·교육) 적극 활용 여지
  • 고벤처포럼 등 창업 커뮤니티 접점에서 초기 모객
  • 콘텐츠·커뮤니티 = 저비용으로 검증 시작 가능

Threats

  • 정부 무료 창업 교육·콘텐츠의 대체 압력
  • 초기 커뮤니티 운영 = 시간·인력 소모 과다
  • 방향 미정 상태로 예산 태우면 소진 위험

패키징 원칙 — STAGE 0 Land & Expand예비창업엔 선불 대형 견적을 내지 않는다. 입구 = ①방향 확정 워크숍/코칭(소액) + ②정부지원 매칭(선행 호의·비용 거의 0). 목적은 매출이 아니라 관계·졸업 후보 확보. 졸업 트리거 = "사업 모델 확정 + 지원금 확보 → 위 셀렉 기반 본 견적(Phase B) 전환". 트리거 없이 워크숍만 반복하면 저단가 좀비가 되니 반드시 못 박는다.

상담 진행 (8월 고벤처포럼 · 15분)

15분은 처방할 시간이 아니라 정체를 파악할 시간이다. 공개 실체가 없으니 첫 5분은 무조건 사실 수집 — "지금 뭘 파는 게 정해졌나요, 아니면 무엇을 팔지가 고민이세요?" + "지금 나오는 매출이 있나요?"로 STAGE부터 못 박는다. 예비창업이라고 STAGE 1로 반올림하지 말 것.

사업 단계 — 비즈테이블랩 = STAGE 0 (추정)

STAGE 0 · 사업 모델 미정 ★추정
무엇을·누구에게·어떤 순서로 팔지 미정. 매출 0. 여러 방향 개방.
역할 → 방향 워크숍·코칭 + 정부지원 매칭 (퍼널 X)
STAGE 1 · 런칭 전
팔 것 확정, 전환 배관만 없음.
역할 → 첫 매출 경로 세팅 + 포지셔닝
STAGE 2+ · 런칭·매출
제품·채널 있음 / 운영 중.
역할 → 점검·개선 / 캠페인·리테이너
단계 확정 질문 — 여기서 STAGE가 갈린다① 팔 게 정해졌나 vs 무엇을 팔지 고민인가 · ② 지금 매출이 있나. 둘 다 "미정/0"이면 STAGE 0 확정 → 워크숍·정부지원 매칭 트랙. 만약 "이미 뭘 파는지 명확하고 채널만 없다"면 STAGE 1로 이동해 세팅 제안. 라벨(예비창업)이 아니라 이 답으로 판정.

상담 흐름 (15분 압축 3단계)

1 · 정체 파악 (~5분)
브랜드명 어원·배경 청취 → "무엇을 파는가·매출·사업자등록" 확인. 여기서 STAGE·아이템이 드러난다.
2 · 병목 합의 (~5분)
STAGE 0이면 "방향이 아직 여러 갈래"임을 함께 인정. 마케팅이 아니라 방향 확정이 먼저임을 프레임.
3 · 입구 제안 (~5분)
소액 워크숍/코칭 + 예비창업 자금 매칭(더하기 창업 D-16·여성기업)을 선행 호의로 제안 → 관계 개설.
아이스브레이킹"비즈테이블랩 — 이름이 눈에 띄어서요. '비즈니스 테이블'이라니, 창업하는 분들이 둘러앉는 자리를 만드시려는 건가 싶었는데, 이름은 어떻게 지으셨어요?" → 어원에서 사업 본질이 나온다(리서치로 못 잡는 최대 무기).

반드시 물어볼 질문 Top 3

Q1 · 단계·매출·예산 성격 (1순위·필수)
"지금 뭘 파는 게 정해졌나요, 아니면 무엇을 팔지가 고민이세요? 매출은 나오나요? 그리고 이번에 쓰실 예산은 자비 부담인지 / 정부지원금 활용인지 / 월 운영비 성격인지?"
STAGE 확정 + 예산 성격(선불 대형 견적 가능 여부) — 반드시 1번에 고정
Q2 · 브랜드명 어원 (필수 상시)
"'비즈테이블랩'이라는 이름은 어떻게 지으셨어요? Biz+Table+Lab에 담고 싶었던 게 뭐예요?"
웹에 없는 사업 본질·차별점이 어원에서 나온다 (최대 무기)
Q3 · 아이템 방향 · 계약 주체
"콘텐츠·미디어로 신고하셨는데 교육/커뮤니티/매칭 중 어디에 가까우세요? 혼자 하시나요, 팀이 있나요? 사업자등록은 하셨어요?"
아이템 특정 + 실행 주체·법적 상태 확인
예상 반론 대비"홍보·마케팅부터 해주세요" → "방향이 여러 갈래인 상태에서 광고를 깔면 예산만 샙니다. 무엇을 파는지부터 한 장으로 좁히고, 그 다음 채널을 얹는 게 순서예요." · "돈이 별로 없어요" → "그래서 예비창업 자금(더하기 창업·여성기업)을 먼저 붙입니다. 비용 부담 없이 시작하는 게 맞아요." · "혼자서도 할 수 있을 것 같은데" → "물론이죠. 저희는 방향을 함께 잡는 스파링 파트너 — 소액 코칭으로 가볍게 시작하시면 됩니다."
상담 후 액션당일 24h — 감사 + 상담에서 확정된 3줄(STAGE·아이템·예산 성격) + 미확인 변수(수익모델·소재지·팀 구성) 기록 → 방향 워크숍 소개 + 예비창업 자금(더하기 창업 D-16) 링크 동봉. 전달 = 링크 위주로 가볍게(수주 온도 낮음).
STAGE 0 운영룰 — Land & Expand지금 큰 수주를 노리지 말 것. 소액 입구로 관계를 붙잡았다가, 사업 모델 확정 + 지원금 확보(졸업 트리거)가 오면 본 견적으로 졸업시킨다. 고벤처포럼(팁스타운, 매달 마지막 화요일)은 이런 STAGE 0 관계의 기성 모객처.

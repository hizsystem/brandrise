상담 진행 (15분)

15분 짧은 상담 + 예비창업 = 처방보다 분류가 먼저다. 상담은 "지금 파는 게 정해졌나요, 아니면 무엇을 팔지가 고민이세요?" + "지금 나오는 매출이 있나요?"로 연다 — 이 두 답이 STAGE 0/1을 가르고 우리 역할·견적을 결정한다. 톤: 예비창업 대표 = 막연한 "브랜딩" 화법 금지, 구체·단계·다음 액션.

사업 단계 — 오미자랑 = STAGE 0~1 (상담서 확정)

STAGE 0 · 사업모델 미정 ★유력
무엇을·누구에게·어떤 순서로 팔지 미정. 매출 0. 여러 방향 개방.
역할 → 디스커버리 워크숍·방향 코칭(퍼널 X)
STAGE 1 · 런칭 전 ★가능
아이템·타깃 정해짐, 전환 배관만 없음.
역할 → 첫 매출 경로 세팅 + 포지셔닝
STAGE 2~3 · 런칭·운영
해당 없음(예비창업).

단계 판정 룰매출 0 + "무엇을 팔지" 미정/여러 갈래 → STAGE 0(런칭 전이라고 STAGE 1로 반올림 금지). 아이템·가격·방법이 확정됐고 전환 동선만 없으면 → STAGE 1. STAGE 0면 소액 워크숍·Land&Expand, STAGE 1이면 입구형 소형 세팅 패키지.

상담 흐름 (15분 압축 4단계)

1 · 분류 질문(먼저)
"파는 게 정해졌나 / 무엇을 팔지가 고민인가" + "매출 있나" → STAGE 0/1 즉시 판정.
2 · 주체·예산 확인
계약·의사결정 주체(총괄 김가연 vs 대표 성창현) + 예산 성격(자부담/정부지원/단발). 견적을 가르는 축.
3 · 브랜드·아이템
"오미자랑" 어원 + 오미자 형태(청/RTD/선물세트)·타깃(20대 vs 선물수요)·산지. 차별 축의 실마리.
4 · 다음 액션
STAGE 0 → 디스커버리 워크숍 + GovFit(모두의 창업) 안내 / STAGE 1 → 소형 세팅 패키지. §기회·견적 셀렉으로 1차 규모 제시.
아이스브레이킹"오미자가 요즘 20대에서 구매율이 제일 높은 카테고리예요 — RTD·디저트·인스타 감성으로 뜨는 중이라 타이밍은 좋습니다. 다만 문경·장수·인제가 청·선물세트를 이미 꽉 잡고 있어서, '오미자랑'을 어떤 각으로 세울지가 승부처라 오늘 그 방향부터 같이 잡아보면 좋겠어요." → 카테고리 인정 + 진짜 과제(방향) 합의.

반드시 물어볼 질문 Top 3

Q1 · 계약·의사결정 주체 + 사업 단계 (1순위)
"신청은 김가연 총괄님이 주셨는데, 계약·예산 결정은 대표님(성창현)과 함께 하시는 구조일까요? 그리고 — 지금 팔 게 정해졌는지, 아니면 무엇을 팔지가 고민이신지, 나오는 매출은 있는지?"
계약주체 + STAGE 0/1 판정 — 견적·역할·클로징을 모두 가른다
Q2 · 예산 성격
"이번 건은 단발 프로젝트 비용으로 보시는지, 월 운영 대행비인지, 아니면 광고 매체비를 염두에 두신 건지? 창업 자금은 자부담인가요, 정부지원(예창패 등) 계획이 있으신가요?"
과금 구조 = 수용 결정 · 실링·트랙(선불 vs 성과연동 vs 지원금 연계) 확정
Q3 · 브랜드명 "오미자랑" 어원 + 타깃/산지
"'오미자랑'이라는 이름은 어떻게 지으셨어요? (오미자+자랑? +랑?) 오미자는 어느 산지 걸 쓰시고, 청·음료·선물세트 중 어떤 형태로, 누구를 겨냥하세요?"
웹에 없는 최대 무기가 여기서 나옴 — 차별 축·스토리의 실마리
예상 반론 대비"일단 제품부터 만들고 싶다" → "좋습니다, 다만 오미자청은 이미 문경·장수가 꽉 잡아서 — 제품 전에 '누구에게·어떤 각'을 30분만 잡으면 만들 제품이 달라집니다." · "돈이 없다" → "그래서 소액 워크숍으로 시작하고, 모두의 창업 같은 정부지원을 같이 찾아 자금부터 만드는 순서를 권해요." · "내가 다 안다" → "산지·레시피는 대표님이 최고죠. 저흰 그걸 시장 언어로 옮기는 쪽만."
상담 후 액션당일 24h — 감사 + 핵심 3줄(단계·방향·정부지원 입구) + 미확인 변수(계약주체·예산 성격·아이템 형태·타깃·산지·브랜드 어원) 기록 → STAGE 0면 워크숍 안내 + GovFit(모두의 창업) 링크 / STAGE 1이면 소형 세팅 제안. 전달 = 진단·안내는 링크.
졸업 트리거(필수)STAGE 0 진입 시 "사업 모델 확정 + 지원금 확보 → 본 견적(Phase B) 자동 전환"을 명시적으로 건다. 트리거 없으면 저단가 대표가 워크숍 시간만 소모하고 안 넘어온다.

수주 한 장
USP & 진짜 니즈 (가설)
USP = "여주 스마트팜 청년농부가 무농약 설향을 무게제한 없이 따게 하고, 400평 놀이터·딸기음료까지 묶은 딸기 따기 + 농장 피크닉 하루 체험." 진짜 니즈(가설) = 봄 딸기철에만 도는 계절 체험을 연중 도는 로컬 라이프스타일 브랜드(굿즈·가공식품·B2B·비수기 콘텐츠)로 자산화하는 것. 이미 평당 20~23만원(일반 8~15만)·재방문 30%+·연 4,300명 방문으로 오프라인 상품성은 검증됨. 빈 곳은 비수기 매출·전국 인지·2차 상품(가공·굿즈).
그래서 우리가 해주는 것 (HIZ 보유 역량 안에서)
① 브랜드 축 뾰족화 — "피크니코 = 여주 딸기 피크닉" 한 줄 + 계절→연중 확장 서사 정리(네이밍 자산 활용)
② 예약 모객 콘텐츠 — 인스타·릴스·후기 UGC로 성수기 예약 전환 + 비수기 브랜드 노출(대표 마케팅 감각과 협업)
③ 6차산업 확장 설계 — 딸기잼·굿즈·B2B(카페납품)·연중 체험(육묘·식농교육)까지 농촌융복합 상품·정부지원 매칭
첫 제안 & 다음 액션
STAGE 0 소액 입구 — 브랜드·확장 방향 워크숍/코칭(소액) + 농촌융복합(6차산업) 정부지원 매칭으로 관계부터. 매출·굿즈 방향이 서면 → 브랜딩·콘텐츠·예약전환 본 견적으로 졸업(Land&Expand). 상담 1순위 청취 = 예산 성격(자비 vs 지원금) · 연중화 계획 · 온라인 매출 현황.

상담 진행 (8월 고벤처포럼 · 20분)

상담은 항상 "대표님, 지금 사업 단계 알려 주세요 + 지금 파는 게 정해졌나요/무엇을 팔지 고민인가요 + 매출 나오나요"로 연다. 피크니코는 딸기 체험은 이미 운영·매출(STAGE 2~3), 확장축(연중화·가공·굿즈·B2B)은 방향 여러 갈래(STAGE 0)인 이중 구조. 20분이라 핵심만 — 성과 인정 → 확장축 한 개로 좁히기 → 소액 입구·정부지원 레버 제시.

사업 단계 — 피크니코 = 코어 STAGE 2~3 / 확장축 STAGE 0

STAGE 0 · 확장축 미정 ★
가공·굿즈·B2B·연중화 등 다음 상품이 여러 갈래. 무엇부터 팔지 미정.
역할 → 워크숍·정부지원 매칭(소액·관계)
STAGE 2~3 · 코어 운영 중 ★
딸기 체험 운영·매출·재방문 검증. 성수기 모객이 관심사.
역할 → 예약 콘텐츠·브랜드 축 정리
STAGE 1 · 런칭 전
해당 약함 — 코어는 이미 런칭됨.
역할 → (신규 2차 상품 런칭 시 적용)
단계별 질문 — 이중 구조 세트로 연다① 지금 매출은 딸기 체험이 전부인가·다른 수입(굿즈·가공·B2B) · ② 비수기(여름~겨울)엔 뭘 하나 · ③ 확장 계획(육묘·식농교육·가공) 중 1순위 · ④ 예약·홍보 지금 어떻게 하나(누가 운영) · ⑤ 예산 성격 — 자비 vs 지원금(6차산업·청년농). 확장축이 여러 갈래면 STAGE 0 워크숍부터.

상담 공통 흐름 (20분 압축 4단계)

1 · 소개·인정 (3분)
청년 스마트팜·수익성·재방문 인정으로 연다. 대표 마케팅 경력도 짚어 눈높이 맞춤.
2 · 단계·매출 구조 (5분)
"딸기 체험이 매출 전부인가 / 비수기엔 뭘 하나 / 굿즈·가공·B2B 있나". 온라인 판매·2차 상품 실태를 여기서 확정.
3 · 확장축 좁히기 (7분)
여러 갈래(육묘·식농교육·가공·굿즈) 중 1순위 하나로 좁힌다. 예산 성격(자비 vs 지원금) 확인 → 입구 결정.
4 · 소액 입구·정부지원 (5분)
브랜딩/콘텐츠 소액 단발 + 6차산업 지원 매칭 제시. §기회·견적 셀렉으로 1차 견적을 즉석에.
아이스브레이킹"판교에서 마케팅 하시다 여주에서 스마트팜 1기로 딸기농장 여신 스토리 자체가 브랜드예요. 평당 20만 넘고 재방문 30%면 상품은 이미 증명됐고 — 이제 이 '피크니코'를 딸기철 말고도 도는 브랜드로 어떻게 넓히느냐가 남은 숙제로 보였어요." → 즉시 신뢰 + 진짜 과제(연중화) 합의.

반드시 물어볼 질문 5개

Q1 · 예산 성격 (1순위·고정)
"확장은 자비로 태우실 생각이세요, 아니면 6차산업·청년농 지원금 받아서 하실 생각이세요? 지금 홍보·운영에 월/연 얼마나 쓰세요?"
입구 결정(소액 vs 지원금 매칭) · 계약 주체
Q2 · 브랜드명 어원 (상시 포함)
"'피크니코' 이름은 어떻게 지으셨어요? 피크닉에서 오신 건가요? 담고 싶었던 의미가 있으세요?"
웹에 없는 브랜드 서사 — 최대 무기 발굴
Q3 · 매출 구조·비수기
"매출이 딸기 체험이 거의 전부인가요? 굿즈·딸기잼·B2B 납품 같은 다른 수입은요? 여름~겨울엔 농장이 어떻게 돌아가요?"
계절성·2차 상품 실태 확정
Q4 · 확장축 1순위
"말씀하신 육묘장·식농교육농장·가공 중에 제일 먼저 하고 싶은 게 뭐예요? 왜 그거예요?"
여러 갈래 → 하나로 좁히기(STAGE 0 핵심)
Q5 · 운영 리소스·기대
"예약·인스타·후기 관리는 지금 대표님이 직접 하세요, 다른 분이 있으세요? 저희한테 딱 하나 기대하신다면요?"
실행 리소스 + 대행 vs 코칭 핏
예상 반론 대비"딸기철엔 이미 예약 꽉 찬다" → "맞습니다, 그래서 비수기·2차 상품이에요 — 지금 자산(스토리·설향)을 연중 도는 굿즈·콘텐츠로 넓히는 겁니다." · "마케팅은 제가 해요" → "감각 있으신 거 압니다. 저흰 대신 하는 게 아니라 확장 구조·정부지원 레버를 같이 설계하는 역할이에요." · "돈이 없다" → "그래서 6차산업·청년농 지원금부터 매칭하고, 소액 워크숍으로 방향부터 잡습니다."
상담 후 액션당일~24h — 감사 + 핵심 3줄(브랜드 서사·연중화·6차산업 레버) + 미확인 변수(온라인 매출·2차 상품·예산 성격·확장 1순위) 기록 → 소액 워크숍 제안 + 정부지원 후보 링크 발송. 견적은 수주↓ 성격이라 링크로 가볍게.
STAGE 0 졸업 트리거소액 관계로 붙잡되 좀비화 방지 — "확장축 확정 + 지원금 확보 → 본 견적(브랜딩·콘텐츠·예약전환) 자동 전환"을 처음부터 명시. 고벤처포럼(농어촌공사) 맥락상 지원금 매칭이 자연스러운 입구.

수주 한 장
USP & 진짜 니즈 (가설)
USP(자사 표기 기준·미검증) = "치료도우미동물 인증 미니어처호스 '월리' — 접근장벽 낮은 소형 말 IP로 치유·교육·브랜드 콘텐츠를 한 몸에 가진 사업자." "국내 유일"은 인증기관·인증번호 원부 미확인 — 상담에서 질문으로 확인 진짜 니즈 = 팔로워 10만+·30여 협업자사 표기의 인지도를 지속·반복 매출(서비스 단가표·교육·협찬 패키지·굿즈)로 화폐화하고, 여러 갈래(치유·교육·IP마케팅·관광)를 하나의 브랜드 축으로 정렬하는 것. 병목은 '인지도'가 아니라 '인지도의 화폐화'. 봉사·명예대사·캠페인으로 쌓은 화제성이 유료 상품·B2G 계약·협찬 매출로 아직 다 이어지지 않았다(가설).
그래서 우리가 해주는 것 (HIZ 보유 역량 내)
① 브랜드 축 정리 — 치유·교육·IP·관광으로 벌어진 활동을 "월리 = 무엇" 한 줄로 (봉사/공익 이미지 ↔ 유료 사업의 관계 정리)
② IP 수익화 설계 — 10만 오디언스 → 협찬 패키지(LITE/STD/PREMIUM 가격·기준)·굿즈·멤버십·B2G 제안서로 상품화
③ 콘텐츠·모객 시스템 — 강한 오가닉 콘텐츠를 예약·문의·계약 전환 배관에 연결 + 후원/B2G 채널 개척
첫 제안 & 다음 액션 (STAGE 0 Land&Expand)
서비스/IP업 + 유료화 의지 미확인 → 선불 대형 용역 대신 소액 포지셔닝·IP 수익화 워크숍(1:1 코칭)으로 입구 + 정부지원(소상공인 판로·사회적기업) 매칭으로 관계. 모델·매출 잡히면 본 견적(브랜딩·콘텐츠·IMC)으로 졸업. 미팅 1순위 청취 = 현재 매출 출처·계약주체(월리플랍 개인/법인)·유료화 의지.

상담 진행 (8월 고벤처포럼 · 20분)

상담은 항상 "대표님, 지금 현재 사업 단계 알려 주세요" + "지금 파는 게 정해졌나요, 무엇을 팔지가 고민인가요?" + "지금 매출은 어디서 나오나요?"로 연다. 신청은 '초기'지만 인지도·채널은 STAGE 2~3, 수익모델은 STAGE 0 성격이 혼재 — 라벨로 반올림하지 말 것. 톤: 봉사·공익 진정성 존중 + "그 좋은 인지도를 지속가능한 매출로" 프레임. 20분이라 질문 밀도 우선.

사업 단계 — 월리 = 인지도 STAGE 2~3 / 수익모델 STAGE 0

STAGE 0 · 사업모델 미정렬 ★월리
인지도·채널은 갖췄으나 무엇을 주력으로·어떻게 팔지 미정렬(치유·교육·협찬·굿즈·관광 병렬).
역할 → 포지셔닝·IP 수익화 워크숍(소액·1:1) + 정부지원 매칭
STAGE 1~2 · 상품·전환 세팅
주력 정해지면 서비스 단가표·협찬 패키지·예약/문의 전환 배관.
역할 → 상품화 · 자사 허브 세팅
STAGE 3 · 매출 드라이브
반복 매출·B2G 파이프라인 운영 단계.
역할 → 콘텐츠·IMC·후원/B2G 리테이너
단계별 질문 — STAGE 0 세트로 연다① 현재 매출 출처·비중(치유 봉사/유료·교육·협찬·굿즈·관광) · ② 유료 서비스 단가표 유무 · ③ 계약주체(월리플랍 개인/법인)·정산 · ④ 10만 오디언스의 문의·전환 데이터 · ⑤ 봉사↔유료 목표 밸런스·다음 성장축. 주력이 정해져 있으면 상품화·전환 세팅 단계로 넘어간다.

상담 공통 흐름 (20분 압축 4단계)

1 · 소개 청취
월리·사업·대표 배경을 듣는다(프랩 인지한 채로). 봉사·공익 스토리를 먼저 인정.
2 · 단계·매출 출처 체크
"현재 단계?" + "무엇을 팔지 정해졌나?" + "매출은 어디서?" — 치유(유/무료)·교육·협찬·굿즈·관광 중 주력이 어디고 비중 몇 대 몇인지 · 유료 단가표가 있는지.
3 · 문제 도출
인지도 있음 → 왜 매출로 안 남나(단가표·전환배관·상품 패키지 부재) / 축이 흩어짐 → 무엇을 마스터로 앞세울지. STAGE 0 = 우선순위·포지셔닝 문제로 도출.
4 · 입구 제안
선불 대형 용역 대신 소액 IP 수익화·포지셔닝 워크숍 + 정부지원 매칭을 입구로 제시. 셀렉은 진단·포지셔닝 블록만 소액으로.
아이스브레이킹"월리 콘텐츠랑 봉사 활동 쭉 봤어요 — 자사 채널에 팔로워 10만+로 표기하신 걸 봤는데, 소형 말로 이만한 오디언스를 만든 사례가 흔치 않더라고요. 그런데 그 인지도가 아직 지속 매출로는 다 안 이어진 것 같아서 그 얘길 나누고 싶었어요." → 즉시 신뢰 + 진짜 과제 합의. 인증·협업은 단정 말고 질문으로: "치료도우미동물 인증은 어디서 어떤 절차로 받으신 거예요? 인증번호가 있으면 마케팅에서 훨씬 세게 쓸 수 있습니다." / "BMW·롯데 협업도 하셨다고 봤는데 어떤 형태였나요?"
⚠️ 미검증 게이트발화 금지 3건 — 근거가 전부 자사 표기 단독이다. ①"국내 유일" 치료도우미동물 인증 소형 말 — 인증기관·인증번호 원부를 확인하지 못했다. 최상급을 단정했다가 반박당하면 문서 전체 신뢰가 무너진다. ②팔로워 10만+·누적 조회 1억+ — IG·YT·TikTok 모두 로그인 필요로 실측 미검증. 말할 때는 반드시 "자사 채널에 ~로 표기하셨던데"로 출처를 붙인다. ③BMW·롯데·Disney·KIA 등 30+ 협업 — 자사 사이트 표기뿐이고 브랜드사 발표·보도 확인 0건. 실명을 우리 입으로 먼저 확정하지 말고 대표가 말하게 한다. 확인되는 순간부터 최대 무기로 쓴다.

Q3 · 매출 구조

Q4 · IP 수익화 의지

Q5 · 확장 · 리스크

예상 반론 대비"우린 봉사·공익이 우선" → "그 진정성이 브랜드의 힘입니다. 다만 지속하려면 유료 사업이 봉사를 받쳐줘야 — 그 구조를 설계하자는 거예요." · "홍보는 우리가(오가닉) 잘한다" → "맞습니다, 콘텐츠 도달은 이미 최상위예요. 비는 건 도달을 문의·계약으로 바꾸는 배관과 상품 패키지입니다." · "예산이 넉넉지 않다" → "그래서 큰 용역 대신 소액 워크숍부터. 정부지원(소상공인 판로·사회적기업)도 같이 매칭해 드립니다."
상담 후 액션당일 24h — 감사 + 핵심 3줄(브랜드 축·IP 수익화·전환 배관) + 미확인 5변수(매출 출처·유료 단가표·계약주체·예산 성격·확장 우선순위) 기록 → 소액 워크숍 제안 + (요청 시) 정부지원 1~2건 링크. 전달 형태 = 진단·제안서는 링크(무조건).

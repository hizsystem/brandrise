뉴트리오 (Nutrio)

"Nutrio = nutrition" — 이름만 보면 영양·식품·헬스 방향으로 추정되는 예비창업 아이템. 대표(이양진)가 무엇을·누구에게 팔지는 공개기록으로 확인되지 않음 — 동명 타사(라이코스펫 nutrio 펫푸드 등)와 섞이지 않게, 상담 첫 15분에 아이템 실체부터 특정해야 하는 STAGE 0.

수주 한 장
USP & 진짜 니즈 (가설)
USP = 아직 미확정. 확인된 건 브랜드명 Nutrio(=nutrition 어원) 하나뿐. 진짜 니즈(추정) = 광고·마케팅 이전에 "무엇을·누구에게 파는지"(아이템·타깃 정의) 그 자체. "nutrio" 이름을 쓰는 펫푸드·영양제·앱이 이미 여럿(라이코스펫 nutrio 등) → 상담 초반 5분 안에 "이양진님 아이템"을 특정하지 못하면 나머지 대화가 공회전한다.
그래서 우리가 해주는 것 (STAGE 0)
① 아이템·타깃 특정 — "무엇을 / 누구에게 / 왜 Nutrio인가"를 한 줄로 뽑는 포지셔닝 정리
② 네이밍·상표 점검 — 동명 다수(펫푸드·영양제) → 상표·검색 가시성 리스크 진단
③ STAGE 0 로드맵 — 예비창업패키지 등 정부지원 매칭 + 소액 브랜드 워크숍으로 관계부터
첫 제안 & 다음 액션
유료 딥다이브 아님. STAGE 0 소액 워크숍 / 1:1 코칭 + 예비창업패키지 매칭으로 관계 먼저. 미팅 1순위 청취 = "아이디어 단계인가 / 팔 게 정해졌나 / 지금 자본·시간 여력" 3가지.

예비창업자 — 자본·시간·팀 구성·시제품 유무 모두 미확인. 아이디어 단계인지 사업계획 단계인지부터.

USP 상태 — 아직 정의 전예비창업 단계라 USP는 '못 옮기는' 게 아니라 '아직 정하지 않은' 상태다. 처방은 새 광고 캠페인이 아니라 포지셔닝·네이밍 워크숍 — "무엇을 누구에게"를 먼저 문장으로 만드는 것.

상담 진행 (8월 고벤처포럼 · 15분)

상담은 항상 "지금 사업 단계 어떠세요?" + "무엇을 팔지 정해졌나요, 아직 아이디어 단계인가요?" + "지금 자본·시간 여력은?" 3개로 연다. 15분이라 아이스브레이킹 후 곧장 아이템 특정으로 들어간다.

사업 단계 — Nutrio = STAGE 0

STAGE 0 · 아이디어(예비) ★Nutrio
팔 게 미정 / 여러 갈래
퍼널 이전. 포지셔닝·네이밍·소액 워크숍이 먼저.
역할 → 아이템 특정 + 정부지원 매칭
STAGE 1 · 팔 것 정해짐
전환 배관만 없음
제품·타깃 확정, 채널·자사몰 미구축.
역할 → 입구형 소형 패키지
STAGE 2 · 런칭/운영
제품·채널 있음
"잘 됐나?" 점검 → 개선.
역할 → 점검·리뉴얼
단계별 질문 — STAGE 0 세트로 연다① 무엇을·누구에게(아이템 특정) · ② 아이디어 단계 vs 시제품·사업계획 있음 · ③ 자본·시간·팀 여력 · ④ 브랜드명 'Nutrio' 확정·상표 확인 여부 · ⑤ 예비창업패키지 등 정부지원 신청 계획. 팔 게 정해졌다면 바로 STAGE 1 질문(채널·전환)으로 전환.

상담 흐름 (15분 압축 4단계)

1 · 소개 청취 (~3분)
이양진님 배경·왜 Nutrio를 시작하려는지. 메모하며 시작.
2 · 단계·아이템 특정 (~5분)
"팔 게 정해졌나 / 아이디어 단계인가" + "식품인가 서비스인가". 여기서 STAGE 0/1 판정.
3 · 문제 도출 (~4분)
아이템 있음 → 포지셔닝·네이밍·채널 우선순위 / 없음 → 무엇부터 정할지·정부지원 매칭.
4 · 다음 스텝 (~3분)
STAGE 0 워크숍/코칭 + 예비창업패키지 안내로 관계 연결. (본격 견적은 아이템 확정 후)
아이스브레이킹"Nutrio, nutrition에서 오신 거죠? 이름은 직관적이에요. 그런데 같은 이름 쓰는 펫푸드·영양제가 이미 여럿이라 — 오늘은 짧으니 '무엇을 누구에게 파는지'부터 같이 정리해봐요." → 어원 존중 + 곧장 핵심.

반드시 물어볼 질문 5개

Q1 · 자본·단계 (1순위)
"지금 창업에 쓸 수 있는 자본·시간은 어느 정도세요? 사업자등록이나 투자 유치는 아직 전인가요?"
예산 성격 + 계약주체 + 단계 확인
Q2 · 브랜드명 어원 / 네이밍
"뉴트리오라는 이름은 어떻게 지으셨어요? nutrition에서 오신 거죠? 같은 이름 쓰는 곳이 많은데 상표는 확인해 보셨어요?"
어원 스토리 + 동명 리스크 인지 확인
Q3 · 아이템 특정
"무엇을·누구에게 파실지 정해졌나요, 아니면 아직 여러 갈래로 고민 중이신가요?"
STAGE 0 vs 1 판정의 핵심
Q4 · 제품 vs 서비스
"영양/식품/헬스 쪽이 맞나요? 만드시려는 게 제품(식품)인가요, 아니면 서비스·앱인가요?"
업종·필요 역량·자본 규모 판별
Q5 · 기대
"오늘 이 상담에서 딱 하나 얻고 싶은 게 있다면 뭘까요?"
진짜 니즈 + 다음 스텝 설계
예상 반론 대비"아직 초기라 마케팅은 이르지 않나요?" → "맞아요, 그래서 지금은 광고가 아니라 '무엇을 누구에게'를 정하는 포지셔닝과 정부지원 매칭이 먼저예요." · "이름부터 정해야 하나요?" → "Nutrio는 좋은데 동명이 많아 상표·검색만 짚고 가면 돼요, 지금 바꾸자는 건 아니에요."
상담 후 액션당일 — 감사 + 아이템 특정 여부(STAGE 0/1) + 자본 여력 메모 → 아이템 있으면 소액 워크숍 제안, 없으면 예비창업패키지 안내 링크 + 포지셔닝 코칭 제안. 개인 연락처는 내부 배정시트로만.

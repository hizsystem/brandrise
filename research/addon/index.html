실체 미확인

"애드온"은 광고·IT·시스템·자동차용품 등 동명이 다수라, 바이오·헬스 + 이의곤 대표로 좁혀도 공개기록이 특정되지 않았다. 무엇을 하는 회사인지가 상담 첫 확인 과제.

의사결정 구조

신청·직함이 홍태웅 주임(실무자), 공개 대표는 이의곤. 오늘 자리에 결정권이 있는지, 대표 전달용 자리인지에 따라 상담 목표·클로징이 완전히 갈린다.

High

단계 미상 (STAGE 0 vs 1)

"초기"는 팔 게 정해진 STAGE 1과 방향이 여러 갈래인 STAGE 0을 함께 덮는다. "무엇을 팔지 정해졌나 / 매출 나오나"로 못 박기 전엔 처방이 반올림된다.

진단 결론 (가설)지금은 진단이 아니라 "특정"이 먼저다. 초기 바이오·헬스는 규제(식약처 웰니스/의료기기 구분)·인허가·자금이 성패를 가르므로, 마케팅 처방을 얹기 전에 사업 단계와 팔 것을 확정해야 한다. 20분 상담의 목표 = 실체·단계·권한 확인 + 관계 열기.
정직 고지 — 억지 진단 금지이 배치는 예비창업·극초기가 많아 공개정보가 거의 없는 곳이 다수다. 애드온도 여기에 해당해 지어내지 않고 "미확인 → 확인 질문"으로 전환했다. 상담에서 대표/제품이 확인되면 그때 진단을 채운다.

상담 진행 (고벤처포럼 · 20분)

실체 미확인이라 20분은 "확인 → 관계 열기"가 목표다. 제안·수주가 아니라 실체·단계·권한 3가지를 먼저 듣고, 오늘 결정권이 없으면 대표(이의곤)와의 다음 연결을 확보한다. 톤: 초기 실무자에게 막연한 "브랜딩" 화법 금지 — 사업 단계·규제·자금 같은 실무 언어로.

사업 단계 — 애드온 = STAGE 0~1 (미확정, 상담에서 확정)

STAGE 0 · 사업 모델 미정 ★가설
매출 0 + 무엇을·누구에게 팔지 여러 갈래. 초기 바이오·헬스 다수가 여기.
역할 → 포지셔닝·우선순위 워크숍 + 정부지원 매칭
STAGE 1 · 런칭 전 ★가설
팔 게 정해졌고 전환 배관만 없음.
역할 → 첫 매출 경로 세팅 + 브랜드 기본기
STAGE 2~3 · 런칭 이후
제품·채널·매출 있음. (초기 신청이라 가능성 낮음)
역할 → 점검·개선 / 리테이너
단계 분류 질문 — 여기서 STAGE 0/1을 못 박는다① 지금 파는 게 정해졌나요, 무엇을 팔지가 고민인가요? · ② 지금 매출 나오세요? · ③ 제품이 건기식/화장품/의료기기 중 어디에 해당하나요(규제 트랙)? — 매출 0 + 방향 여러 갈래면 STAGE 0(워크숍·소액), 팔 게 정해졌으면 STAGE 1(전환 배관).

상담 공통 흐름 (20분 압축 4단계)

1 · 실체·권한 청취 (0~5분)
"애드온이 어떤 걸 하는 회사인지" + "오늘 오신 분(홍태웅 주임)이 방향을 정하시는지, 대표님(이의곤)께 전달하시는 자리인지" — 권한 구조를 먼저 잡는다.
2 · 사업 단계·예산 성격 (5~11분)
위 분류 질문으로 STAGE 0/1 확정 + 예산 성격(정부지원 기대 / 자체 자금 / 아직 없음)을 짚는다.
3 · 문제 도출 (11~16분)
STAGE 0 → 무엇을 팔지·포지셔닝 · STAGE 1 → 첫 매출 경로. 오늘 손댈 수 있는 문제 1개로 좁힌다.
4 · 다음 연결 (16~20분)
소액 워크숍·정부지원 매칭을 입구로 제시 + 대표 미팅/후속 연락을 잡는다. 오늘 견적 확정 아님.
아이스브레이킹"바이오·헬스는 '어떻게 알릴까'보다 '무엇을·어떤 규제 트랙으로 파는가'가 먼저 정해져야 마케팅이 헛돌지 않더라고요. 오늘은 애드온이 지금 어느 단계인지부터 편하게 들려주세요." → 실무자 눈높이 + 신뢰.

반드시 물어볼 질문 Top 5

Q1 · 권한·계약 주체 (1순위)
"오늘 방향을 여기서 정하실 수 있는 자리인가요, 대표님(이의곤)께 전달하시는 자리인가요? 나중에 진행하면 계약·예산은 어디서 결정되나요?"
주임 신청 → 결정권 위치 확인. 없으면 목표를 '다음 연결'로 전환
Q2 · 예산 성격 (필수 고정)
"이번에 쓰실 수 있는 게 정부지원금 기대인지 / 자체 예산인지 / 아직 없는 단계인지? 단발 프로젝트비인지 월 운영비인지?"
STAGE 0 소액 입구 vs 정부지원 매칭 갈림 — 선불 대형 용역 부적합 판별
Q3 · 사업 단계 / 파는 것
"지금 파는 게 정해졌나요, 무엇을 팔지가 고민인가요? 매출은 나오세요? 제품이 건기식/화장품/의료기기 중 어디에 드나요?"
STAGE 0/1 확정 + 규제 트랙
Q4 · 브랜드명 어원
"'애드온(Add-On)'이라는 이름은 어떻게 지으셨어요? 무엇에 무엇을 '더한다'는 의미인가요?"
웹으로 못 잡는 최대 무기 — 포지셔닝·차별점의 실마리가 여기서 나온다
Q5 · 오늘의 기대 / 시급 과제
"고벤처포럼 상담에서 가장 얻고 싶은 게 뭐였어요? 지금 가장 급한 한 가지는?"
니즈 표면 확인 + 다음 액션 설계
예상 반론 대비"저는 실무자라 결정은…" → "그럼 오늘은 방향만 같이 정리하고, 대표님과의 자리를 잡는 걸 목표로 하죠." · "아직 초기라 예산이 없다" → "그래서 오늘은 비용 얘기가 아니라, 초기에 맞는 정부지원 트랙과 우선순위부터 봅니다." · "뭘 도와줄 수 있냐" → "무엇을 파실지·어떤 규제 트랙인지가 정해지면, 포지셔닝과 첫 매출 경로를 소액 워크숍으로 같이 그립니다."
상담 후 액션당일 24h — 감사 + 핵심 3줄(실체·단계·권한 확인 결과) + 미확인 변수(정식 상호·업종 세부·매출·예산·결정권) 기록 → STAGE 판정 확정 후 소액 입구/정부지원 안내. 전달 = 진단서 링크 / 견적은 초기이므로 링크로 가볍게.
특정 재시도 룰상담에서 정식 상호(법인명)·업종 세부를 확보하면 사람인·크레딧잡·기업마당·GovFit 재호출로 프로필을 정밀화하고 이 PREP를 갱신한다. (오늘까지 공개기록 특정 실패 — 실체 확인이 최우선.)
